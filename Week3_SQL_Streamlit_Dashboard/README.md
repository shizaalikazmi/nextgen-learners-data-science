# Week 3 – SQL and Streamlit Internship Dashboard

## Project Overview
This project is part of the NextGen Learners Data Science Internship Program. It uses SQLite for data storage and SQL queries for data analysis. A Streamlit dashboard is developed to visualize internship performance.

## Features
- SQLite database with three tables: applicants, interns, and hackathon_scores.
- Domain-based dashboard filter.
- Total applicants and interns metrics.
- Intern completion analysis.
- Average hackathon score by domain.
- Top 10 performers leaderboard.
- Applicant conversion analysis by domain.

## Technologies Used
- Python
- SQLite
- SQL
- Pandas
- Streamlit
- Matplotlib

## How to Run
1. Install the required libraries:
   `pip install -r requirements.txt`
2. Run the dashboard:
   `streamlit run dashboard.py`
3. The dashboard will open in your browser.

## Note
All applicant, intern, completion-status, and hackathon-score data used in this project are fictional and created for learning purposes.
